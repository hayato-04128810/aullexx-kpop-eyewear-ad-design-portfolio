# aullexx-kpop-eyewear-ad-design-portfolio
韓国アイウェアブランド「AULLEXX」名古屋店新規オープンに伴う、Z世代・K-POPファン向け広告バナーのデザイン制作物（PDF）です。

どのような人に向けた広告か

K-POPや韓国ストリートファッションが好きな10代後半〜20代の男女をターゲットにしています。特に、流行を取り入れながらも、自分らしいファッションや個性を表現したい人に向けた広告です。

何を伝えたいのか

韓国発のプレミアムアイウェアブランド「AULLEXX」が名古屋に新しくオープンすることを伝えています。メガネを単なる視力補助用品ではなく、ファッションや個性を表現するアイテムとして楽しんでもらうことを意識しました。

どんな印象を与えたいのか

白と黒を基調としたシンプルなデザインに、黄色のカラーレンズをアクセントとして使用しました。韓国ブランドらしい洗練されたクールさ、近未来感、高級感を感じてもらい、「かっこいい」「自分も身につけてみたい」と思ってもらえる広告を目指しました。
